# 우리 반 세계 재해 지도

같은 **학급 코드**로 접속한 교사와 학생이 세계지도에 자연재해 핀과 메모를 함께 작성하는 실시간 웹사이트입니다.

## 준비물

- Node.js 18 이상
- 인터넷 연결: 지도의 OpenStreetMap 타일과 Leaflet 라이브러리 로드에 필요

## 컴퓨터에서 시작하기

1. 이 폴더를 압축 해제합니다.
2. 이 폴더에서 터미널(Windows: 파일 탐색기 주소창에 `cmd` 입력)을 엽니다.
3. 다음 명령어를 차례대로 입력합니다.

```bash
npm install
npm start
```

4. 브라우저에서 `http://localhost:3000`에 접속합니다.
5. 학급 코드와 이름을 입력합니다. 다른 학생도 **같은 주소**와 **같은 학급 코드**를 사용하면 실시간으로 연결됩니다.

> `localhost` 주소는 실행한 컴퓨터에서만 접속됩니다. 다른 학생이 자기 기기에서 접속하려면 아래 배포 절차를 따르세요.

## 인터넷에 배포하기

1. GitHub에 이 프로젝트 폴더의 파일을 새 저장소로 업로드합니다. `node_modules`나 `data/rooms.json`은 업로드하지 마세요.
2. Node.js 웹서비스를 지원하는 호스팅(예: Render의 Web Service)을 생성하고 GitHub 저장소를 연결합니다.
3. Build Command는 `npm install`, Start Command는 `npm start`로 설정합니다.
4. 서비스가 발급한 HTTPS 주소를 학생들에게 공유합니다.
5. **재시작 후에도 기록을 유지하려면 반드시 영속 디스크가 필요합니다.** 호스팅이 제공하는 영속 스토리지를 마운트하고 `DATA_DIR` 환경변수를 해당 디렉터리로 설정하세요. 예: 디스크 마운트 경로 `/var/data` → `DATA_DIR=/var/data`. 영속 디스크가 없는 무료 호스팅은 재배포/재시작 시 기록이 사라질 수 있습니다.
6. 서버가 중지되거나 인터넷에 연결되지 않으면 실시간 협업이 동작하지 않습니다.

## 사용 방법

- 지도의 빈 곳 클릭 → 새 메모지 작성 후 저장
- 지도 핀 또는 좌측 기록 클릭 → 메모 열람, 수정, 삭제
- 같은 학급 코드면 변경 내용이 실시간으로 모든 화면에 표시
- 재접속해도 같은 서버와 학급 코드에 저장된 핀은 다시 표시
- 학급 코드를 다르게 입력하면 독립적인 지도가 열림

## 수업 운영 시 유의사항

- 학생들에게 실명보다 별명이나 번호 사용을 권장합니다.
- **간편 학급 코드 방식이며 인증·권한 관리가 없습니다.** 학급 코드를 아는 누구나 입장하여 기록을 수정하거나 삭제할 수 있습니다. 민감한 개인정보나 비밀 자료를 올리지 마세요.
- 학급당 핀 250개, 메모당 1,500자까지 지원합니다.
- 서버 데이터는 `data/rooms.json`에 저장됩니다. 수업 전후로 이 파일을 안전한 곳에 백업하는 것을 권장합니다.
- 이 버전은 서버 인스턴스 하나에서 사용하도록 설계했습니다. 여러 서버를 띄우는 확장 환경에서는 공유 데이터베이스/Socket.IO 어댑터 구성이 추가로 필요합니다.
- 지도 데이터는 © OpenStreetMap contributors로 출처 표기됩니다. 지도 타일은 OSM의 이용 정책을 준수하고 대규모 사용 시 별도 타일 제공자를 사용하세요.

## 파일 구조

- `server.js`: 실시간 동기화, 데이터 검증 및 저장
- `public/index.html`: 화면 구조
- `public/style.css`: 디자인
- `public/app.js`: 지도, 핀, 메모 기능
- `data/rooms.json`: 최초 기록 저장 후 자동 생성

## 기술

Node.js + Express + Socket.IO + Leaflet + OpenStreetMap. 외부 데이터베이스 계정이나 API 키 없이 실행할 수 있습니다.
